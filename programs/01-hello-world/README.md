# 1. Hello World

**Difficulty:** Beginner | **Category:** Basics

## Description
The classic first Java program that prints a greeting to the console.

## Source Code
```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

## Expected Output
```
Hello, Java!
```

## Explanation
Every Java program needs a class with a main method. System.out.println() writes a line of text to the console.
